## Practice test (in this repo)

`practice-test/` is a timed practice mode: one question at a time, 3 choices each, scored by topic with the weakest topic first. Questions live in `practice-test/questions.txt`, a plain text file anyone can add to. See `practice-test/README.md` for how to run it and how to add questions.

# Track & Field — Cadets

- `build_100_200_plan.py` — generator for the 100m/200m Sprint Training Plan PDF, adapted from Desmond Dunham's 400m framework. This plan is the seed source for the sprinter workout database.
- `sprinter-workout-database/` — searchable library of sprint sessions (see its README).

To add over time: indoor schedule builder, recruiting board data (aggregate marks only, no private contact info), sprint training plan updates.

# aj-vault

AJ Ruffin's private vault — teaching, coaching, CSCS, and life systems built with Muse.
Private. Full version history on everything, so no file is ever lost and any change can be rolled back.

## What's inside

| Folder | What it holds |
|---|---|
| `sports-med/` | Sports Med class materials: lecture decks (generators), worksheets, rubrics, assignments |
| `track/` | Cadets track & field: training plans, recruiting, meet schedules |
| `track/sprinter-workout-database/` | Searchable database of sprint sessions — the long-term build project |
| `cscs/` | CSCS exam prep: study plan, resource pack, quiz data |
| `life-admin/` | Budget, templates, personal systems (no passwords, no sensitive ID numbers — ever) |
| `systems/morning-pictures/` | The builders behind the 5:45 AM schedule picture and 7:45 AM health & consistency picture |

## Rules for this repo

- Private, always. No student or athlete personal information (names with marks/grades/health data stay out).
- No passwords, API keys, or account numbers. Those live in the Secure Vault, not here.
- Big files (textbook PDFs, photo libraries) do not belong here — this is for text, data, and code.
- Every meaningful change gets a clear commit message, so the history reads like a logbook.
